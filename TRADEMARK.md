# Branding

The code in this repository is licensed under the MIT License.

The OffPDF name, logo, and release assets identify the official project. Forks
are welcome, but redistributed builds should avoid implying that they are
official OffPDF releases unless they are published by the project maintainers.

This keeps users from confusing unofficial builds with the trusted download
channel while preserving the freedom to study, modify, and redistribute the
code under the MIT License.
